# 运营常见问题 FAQ

1. **Q：平台目前总用户规模怎么看？**
   A：直接问 AI 助手"目前整体情况如何"，它会调用总量概览接口返回累计注册用户、角色卡总数、消息总数等指标；也可在大屏首屏查看。

2. **Q：为什么今天的注册数看起来比昨天低很多？**
   A：先确认 CDC 同步链路是否正常（同步延迟会导致分析库数据滞后），再看渠道投放是否有变化；两者都正常时通常是自然波动，可对比近 7~30 天趋势判断。

3. **Q：好感度五维分别是什么？怎么提升？**
   A：心动、信任、默契、陪伴、亲密五个维度加权构成总好感度，具体提升途径见《产品手册》五维体系一节；维度权重由运营配置中心控制，可热更新。

4. **Q：关系阶段是怎么划分的？**
    A：按总好感度划分为冷淡、疏远、认识、熟悉、朋友、好友、暧昧、心动、热恋、深爱十个阶段，跨过阈值即升级；各阶段人数占比可通过关系阶段分布接口查看。

5. **Q：角色卡热度排行多久更新一次？**
   A：排行数据依赖分析库小时级聚合任务，最长滞后 1 小时；新上架角色卡需要累积一定交互量后才会进入有效排名。

6. **Q：AI 助手回答里的数字可信吗？**
   A：助手所有运营数字都来自内部 API 实时返回，不自行估算；若接口无数据它会明确说明信息不足。发现口径疑问时以分析库汇总表为准并反馈数据组。

7. **Q：挑战排行榜的统计周期是什么？**
   A：默认按自然周统计用户挑战完成数，每周一凌晨重置；限时活动挑战单独成榜，周期跟随活动配置。

8. **Q：消息量趋势突然暴涨是不是异常？**
   A：结合当日是否有运营活动、新角色卡上线判断；若无明显原因且伴随 AI 调用量异常上涨，需排查脚本刷量并向风控反馈。

9. **Q：AI 助手能查到单个用户的数据吗？**
   A：不能。内部 API 只提供聚合统计，不暴露个人级别明细，这是有意的隐私边界设计。

10. **Q：知识库内容多久维护一次？**
    A：产品玩法、架构文档随版本迭代更新；修改 markdown 后需重新运行知识入库命令向量化生效，通常在版本上线当天完成。
