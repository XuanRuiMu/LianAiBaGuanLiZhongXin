## 一、鉴权流程

管理登录链：`POST /api/guan-li/deng-lu {shou_ji_hao, mi_ma}` → 同库验密码哈希（bcrypt）→
按 `管理员/运营/审核员` 三旗标解析角色（任一为真即可登录，全伪 403 `WU_GUAN_LI_QUAN_XIAN` 且不签发令牌）→
同 `JWT_SECRET` 签发管理令牌（载荷含 `jiaoSe` 回显位，授权一律不取它）→ 响应体回传
`{yong_hu_id, yong_hu_ming, jiao_se, neng_li}` → 后续接口 `Authorization: Bearer <管理令牌>`
或安全 Cookie → 同源验签（HS256 白名单）→ 过期检查 → 黑名单检查 → 按用户吊销检查 →
管理员门禁（查库三旗标）→ 能力门禁（查库角色的能力位含该路由所需位；高危写需 `gao_we`，FP-17 起封禁需 `feng_jin`、封禁申诉审核需 `feng_jin_shen_he`、统计族需 `tong_ji_xie`）。
刷新 `POST /api/guan-li/shua-xin` 每次按查库角色重新签票，角色被回收即 401。
兼容链：和我恋爱吧签发令牌仍可只校验通行（无 `jiaoSe` 声明，门禁照常查库定角色）。
Socket 握手与 HTTP 同源：`handshake.auth.token` 携带同一签发令牌，
握手期验签加按用户吊销检查，已连接套接字挂载吊销守卫，
吊销后存量连接直接断开。
语音合成走双轨：用户 Bearer 令牌或服务间 `X-Internal-Token` 任一通过即放行。

| 字段 | 说明 |
| ---- | ---- |
| yongHuId | 用户编号，管理中心取身份首选 |
| shouJiHao | 用户手机号 |
| jiaoSe | 管理令牌回显字段（`chao_guan`/`yun_ying`/`shen_he_yuan`），仅用于首屏展示；服务端一律按用户编号查库三旗标重新解析角色，该字段不是授权依据 |

| exp | 过期秒级时间戳 |

## 三、ADMIN_PHONES

逗号分隔手机号白名单，仅作一次性初始化引导名单，
需 `BOOTSTRAP_ADMIN=1` 触发启动种子，把已注册账号提权为管理员。
运行期管理员判定一律以用户表管理员字段为准（变更即失效广播），
不以该白名单实时判定。管理中心侧同名引用该键，不自备名单。

## 四、黑名单与按用户吊销

`jwt_blacklist:{jti}`：注销或改密时写入，值为 1，
存活期等于令牌剩余有效期；命中即拒。
`jwt_yong_hu_cheXiao:{yongHuId}`：注销或改密时写入签发毫秒时间戳，
存活期为令牌最大有效期 7 天；判定式为签发时刻小于等于该值则拒，
签发时刻取 `qianFaHaoMiao`，缺失时回退 `iat` 乘 1000。
语音服务降级语义：未配 `REDIS_URL` 时跳过吊销检查（本地开发降级，
生产必须同源配置）；已配但不可用时拒绝请求。

## 五、限频

和我恋爱吧侧统一经 Redis 计数，多实例共享：管理操作 10 次每分、
聊天 30 次每分、AI 请求 15 次每分、常规 100 次每分、
登录与发码另有账号加 IP 双层限流。
限流键策略：已认证按用户编号，未认证按可信链路推导的真实来源 IP。
语音服务保留进程内滑动窗口限流：默认每身份 60 次每 60 秒
（`TTS_RATE_LIMIT` 与 `TTS_RATE_WINDOW_SECONDS` 可配），超限 429。
管理后端限频待 FP-04 按本表管理档实施。
