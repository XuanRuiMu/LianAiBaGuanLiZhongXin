## 一、鉴权流程

管理登录链：`POST /api/guan-li/deng-lu {shou_ji_hao, mi_ma}` → 同库验密码哈希（bcrypt）→
查用户表管理员旗标 → 同 `JWT_SECRET` 签发管理令牌（含 `guanLi=true`）→ 后续接口
`Authorization: Bearer <管理令牌>` → 同源验签 → 过期检查 → 黑名单检查 → 按用户吊销检查 → 管理员门禁。
兼容链：和我恋爱吧签发令牌仍可只校验通行（无 `guanLi` 声明，管理员门禁照常查库）。
Socket 握手与 HTTP 同源：`handshake.auth.token` 携带同一签发令牌，
握手期验签加按用户吊销检查，已连接套接字挂载吊销守卫，
吊销后存量连接直接断开。
语音合成走双轨：用户 Bearer 令牌或服务间 `X-Internal-Token` 任一通过即放行。

## 二、JWT Claims

签发方为管理后端（管理登录）与和我恋爱吧（用户登录）两处，同 `JWT_SECRET` 同源互认。

| 字段 | 说明 |
| ---- | ---- |
| yongHuId | 用户编号，管理中心取身份首选 |
| shouJiHao | 用户手机号 |
| guanLi | 管理令牌声明（管理后端签发为 true，查库复核管理员旗标后放行） |
| jti | 令牌编号，黑名单键后缀 |
| iat | 签发秒级时间戳 |
| exp | 过期秒级时间戳 |
| qianFaHaoMiao | 签发毫秒时间戳，用户吊销比对主键 |
| tokenType | access 或 refresh |
| sub | 旧版兼容字段，无 yongHuId 时回退取身份 |

## 三、ADMIN_PHONES

逗号分隔手机号白名单，仅作一次性初始化引导名单，
需 `BOOTSTRAP_ADMIN=1` 触发启动种子，把已注册账号提权为管理员。
运行期管理员判定一律以用户表管理员字段为准（变更即失效广播），
不以该白名单实时判定。管理中心侧同名引用该键，不自备名单。

## 四、黑名单与按用户吊销

`jwt_blacklist:{jti}`：注销或改密时写入，值为 1，
存活期等于令牌剩余有效期；命中即拒。
`jwt_yong_hu_cheXiao:{yongHuId}`：注销或改密时写入签发毫秒时间戳，
存活期为令牌最大有效期 7 天；判定式为签发时刻小于等于该值则拒，
签发时刻取 `qianFaHaoMiao`，缺失时回退 `iat` 乘 1000。
语音服务降级语义：未配 `REDIS_URL` 时跳过吊销检查（本地开发降级，
生产必须同源配置）；已配但不可用时拒绝请求。

## 五、限频

和我恋爱吧侧统一经 Redis 计数，多实例共享：管理操作 10 次每分、
聊天 30 次每分、AI 请求 15 次每分、常规 100 次每分、
登录与发码另有账号加 IP 双层限流。
限流键策略：已认证按用户编号，未认证按可信链路推导的真实来源 IP。
语音服务保留进程内滑动窗口限流：默认每身份 60 次每 60 秒
（`TTS_RATE_LIMIT` 与 `TTS_RATE_WINDOW_SECONDS` 可配），超限 429。
管理后端限频待 FP-04 按本表管理档实施。

## 六、错误码

401 未授权两种码：缺头或格式错误为 `WEI_SHOU_QUAN`，
验签失败、过期、命中黑名单、命中用户吊销均为 `LING_PAI_WU_XIAO`。
403 为已认证但非管理员。429 为限流 `XIAN_LIU`。
语音服务失败体为中文 `{"提示": "..."}`，文案走 `app/文案.py`：
缺凭证、令牌无效或过期、请求频繁三档。

## 七、语音服务间鉴权

两边键名同为 `INTERNAL_TOKEN`，管理中心侧已对齐，无需改动和我恋爱吧。
和我恋爱吧以后端配置 `TTS_SERVICE_URL`（默认 `http://localhost:8001`）
调用语音合成接口，请求头携带 `X-Internal-Token`，
头部大小写不敏感。语音服务容器内监听 8000，宿主经 `TTS_PORT` 映射。

## 九、管理接口鉴权头规范

管理接口统一要求 `Authorization: Bearer <管理令牌>`（管理后端 `/api/guan-li/deng-lu` 签发），

`X-Internal-Token` 仅用于服务间调用，不作为管理前端凭证。

## 十三、专属前端绑定

管理后端 CORS 只放行白名单来源：`ALLOWED_ORIGINS`＋本地前端源（`http://localhost:5175`、`http://127.0.0.1:5175`）。
非白名单 Origin 一律拒收（CORS 不放行）；无 Origin 非浏览器直调仅放行健康检查，
管理接口无 Origin 照常要求管理令牌（令牌门禁不因无 Origin 豁免）。
生产 `ALLOWED_ORIGINS` 必须显式配置本地前端地址，禁止通配。
