# P5 Agent 内核与检索

## 图谱（`app/agent/graph.py`）

五节点：supervisor（意图路由，高风险意图挂起）→ planner（读记忆＋审批恢复）
→ plan（绑定工具规划）→ execute_tools（执行，SSE 兼容旧端点）
→ reflect（检索未命中反思）→ generate → synthesizer（综合）。

- 检查点：AsyncSqliteSaver 落 `./data/检查点.db`，`thread_id＝会话号`，重启可恢复（`aget_state` 验证）。
- HITL：问题含删除/导出全量/清空/封禁/审批即挂起，`POST /api/chat/stream` 带 `恢复` 字段继续。
- 轨迹：每节点写 `轨迹` 事件，经 SSE `trace` 类型下发（前端解析器白名单忽略，未升级前端不崩）。
- 记忆：working＝20 轮窗口（前端回传）；episodic＝PG 情景记忆，后台异步压缩绝不阻塞主链路；
  semantic＝PG 混合检索召回（置信度＋过期过滤）。
- 护栏：入口 `输入护栏`（注入拦截＋PII 脱敏），文案走 `texts.py`。

## 检索链（`app/记忆/检索链.py`）

向量（HNSW 余弦）＋全文（tsvector simple＋中文子串兜底，因官方镜像无中文分词器）
→ RRF 融合 → CrossEncoder（`bge-reranker-v2-m3`，CPU）精排 → Top-K，强制引用溯源。

> 中文全文为子串兜底是诚实折中：`simple` 配置把中文按整串切词，`@@` 精确匹配极易漏检，
> 故叠加 `ILIKE`。数据量上来后可换 zhparser 镜像。

## 模型网关（`app/网关/网关.py`）

Provider 抽象＋健康检查＋熔断（连续 3 次失败熔断 5 分钟）＋降级链
（主模型 → 备选 → 语义缓存 → 兜底模板）＋单轮 Token 上限＋累计金额上限，
每次调用记 PG 账本。备选/兜底均有单测覆盖。

## 自研轻量 Trace

Span 经 `app/编排/追踪.py` 双写 SQLite（主）＋PG `跟踪跨度`（镜像，失败不阻断），
任一请求按 `跟踪号` 回放。未引入 OTel/Prometheus/Grafana（技术栈纪律）。

## 评测（`app/评测/基准.yaml`＋`tests/test_评测.py`）

- 工具 20 例：respx 模拟后端，断言期望片段＋P95 时延＜5s，CI 常跑。
- 检索 10 例：需嵌入模型＋PG 已入库；缺模型时自动跳过（`嵌入可用` 判完整权重文件）。
- 现状阻塞：模型权重下载通道不可达（镜像站大文件停滞、官方源约 145KB/s，
  3 次前台续传累计 85 分钟仍未下完），`入库.py` 与评测已就绪，网络恢复后一条命令即跑。
