# 部署手册（恋爱吧数据中心 P0）

## 1. 前置条件

| 项目 | 要求 |
| ---- | ---- |
| 操作系统 | Linux（bash）或 Windows 10+（PowerShell 5.1+） |
| Docker | 24+，含 Compose v2 插件 |
| 内存/磁盘 | ≥8GB 内存，≥20GB 可用磁盘 |
| 端口 | 3307、6380、9092、55432、8080、8000、8001、5174（可在环境文件中改） |

## 2. 一键部署

Linux：

```bash
cd infra
./deploy.sh --env dev
```

Windows：

```powershell
cd infra
./deploy.ps1 -env dev
```

`--env` 支持 `dev|test|prod`，脚本复制 `envs/.env.<环境>` 为 `.env` 后 `docker compose up -d`，并轮询三业务服务 `/health`。

生产环境先替换 `envs/.env.prod` 中全部 `MUST-CHANGE` 值（数据库密码、JWT 密钥、内部令牌、管理员密码、前后端公网地址）。

systemd（Linux 生产）：复制 `infra/systemd/love-analytics.service` 到 `/etc/systemd/system/`，修改 `WorkingDirectory` 后 `systemctl enable --now love-analytics`。

## 3. 端口表

| 服务 | 容器内 | 默认宿主端口 | 环境变量 |
| ---- | ------ | ------------ | -------- |
| MySQL | 3306 | 3307 | MYSQL_PORT |
| Redis | 6379 | 6380 | REDIS_PORT |
| Kafka | 9092 | 9092 | KAFKA_PORT |
| 源 PostgreSQL | 5432 | 55432 | SOURCE_PG_PORT |
| 后端 backend-java | 8080 | 8080 | BACKEND_PORT |
| AI 服务 ai-service | 8000 | 8000 | AI_PORT |
| 语音 tts-service | 8000 | 8001 | TTS_PORT |
| 前端 | 80 | 5174 | FRONT_PORT |

## 4. 健康检查

- 后端：`GET http://localhost:8080/health`（另有 `/api/health`）
- AI 服务：`GET http://localhost:8000/health`（另有 `/api/health`）
- 语音：`GET http://localhost:8001/health`（另有 `/api/tts/health`）
- 中间件健康由 compose `healthcheck` 覆盖，业务服务 `depends_on` 限定健康后才启动。

## 5. 凭证说明

- 后端 `/api/v1/**` 需登录（`POST /api/v1/auth/login`）后 `Authorization: Bearer <JWT>`。
- AI 流式问答 `/api/chat/stream` 需同样的 Bearer JWT（与后端共享 `JWT_SECRET`），或服务间调用携带 `X-Internal-Token`。
- 语音合成 `/api/tts/synthesize` 同上。
- 后端 `/api/internal/**` 仅接受 `X-Internal-Token`。
- 健康检查与语音音色列表免凭证。

## 6. 升级步骤

1. `git pull` 拉取新版本。
2. `cd infra && ./deploy.sh --env prod`（脚本自动重新构建业务镜像）。
3. `docker compose ps` 确认全部 `healthy`。
4. 失败回退：`docker compose down && git checkout <上版> && ./deploy.sh --env prod`。

## 7. 备份恢复

见《运维手册》备份章节与 `infra/scripts/` 下 `backup`/`restore` 脚本（各有 `.sh` 与 `.ps1`）。
