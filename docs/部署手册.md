# 部署手册（恋爱吧管理中心 P0）

## 1. 前置条件

| 项目 | 要求 |
| ---- | ---- |
| 操作系统 | Linux（bash）或 Windows 10+（PowerShell 5.1+） |
| Docker | 24+，含 Compose v2 插件 |
| 内存/磁盘 | ≥8GB 内存，≥20GB 可用磁盘 |
| 端口 | 8001、5678、5175、3100（管理端口，可在环境文件中改）；PostgreSQL/Redis 由和我恋爱吧侧提供，管理后端直连同库 |
| 管理前端浏览器基线 | 见 1.2 |

## 1.1 本地一键启动（只起前端＋语音，后端走服务器）

```powershell
./本地启动.ps1 -env dev
```

前置：`VITE_API_BASE_URL` 指向服务器管理后端，且远端 `GET /api/jian-kang` 健康；
`JWT_SECRET` 与服务器同源。脚本校验远端后端健康后，只以后台进程启动管理前端（5175）+ 语音服务（8001），本地不拉后端进程、不直连数据库（`DATABASE_URL` 留空，误配即拒绝启动）。进入地址 http://localhost:5175，登录流程见用户手册登录节。

## 2. 一键部署

Linux：

```bash
cd infra
./deploy.sh --env dev
```

Windows：

```powershell
cd infra
./deploy.ps1 -env dev
```

`--env` 支持 `dev|test|prod`，脚本复制 `envs/.env.<环境>` 为 `.env`、从和我恋爱吧 `/.env` 按 fill-empty 补齐同源键后 `docker compose up -d`，部署管理后端＋语音＋编排（管理前端不进服务器镜像，跑用户本地省资源），并轮询管理后端/语音/编排健康端点。

生产环境先替换 `envs/.env.prod` 中全部 `MUST-CHANGE` 值（管理侧 n8n 凭据）；同源键（`DATABASE_URL`/`REDIS_URL`/`JWT_SECRET`/`ADMIN_PHONES`/`ALLOWED_ORIGINS`）留空，运行时从和我恋爱吧 `/.env` 补齐。

systemd（Linux 生产）：复制 `infra/systemd/love-management.service` 到 `/etc/systemd/system/`，修改 `WorkingDirectory` 后 `systemctl enable --now love-management`。

## 3. 端口表

| 服务 | 容器内 | 默认宿主端口 | 环境变量 | 部署位置 |
| --- | --- | --- | --- | --- |
| 管理后端 | 3100 | 3100 | MANAGEMENT_BACKEND_PORT | 服务器 |
| 管理前端 | 5175 | 5175 | FRONT_PORT | 用户本地（不进服务器镜像） |
| 语音 tts-service | 8000 | 8001 | TTS_PORT | 服务器（随行） |
| 编排 n8n | 5678 | 5678 | N8N_PORT | 服务器（随行） |

共享 PostgreSQL/Redis 由和我恋爱吧侧提供，管理中心不自建、不映射双端口。

## 4. 健康检查

- 管理后端（服务器）：`GET http://<服务器>:3100/api/jian-kang`
- 管理前端（本地）：`GET http://localhost:5175/`
- 语音：`GET http://localhost:8001/health`（另有 `/api/tts/health`）
- 编排：`GET http://localhost:5678/healthz`
- 共享 PostgreSQL/Redis 健康由和我恋爱吧侧保障；管理后端健康 `GET /api/jian-kang` 应 200，管理前端 `GET /` 应 200。
- 思考记录表已随和我恋爱吧 018 迁移落地（幂等可重放）；新库执行迁移器后管理端思考记录接口直接可用，无需降级。

## 5. 凭证说明

- 语音合成 `/api/tts/synthesize` 需 Bearer JWT（与和我恋爱吧同密钥）或服务间 `X-Internal-Token`。
- 健康检查与语音音色列表免凭证。
- 管理后端鉴权：管理后端签发管理令牌（管理员账号登录，见契约第九节）＋用户表管理员旗标门禁（30 秒进程缓存）；和我恋爱吧签发令牌仍兼容只校验。
- 和我恋爱吧 018 思考记录迁移已落地（幂等可重放，新库随迁移器自动执行）；思考记录缺表降级码 `BIAO_QUE_SHI_JIANG_JI` 仅作老库兜底。

## 6. 升级步骤

1. `git pull` 拉取新版本。
2. `cd infra && ./deploy.sh --env prod`（脚本自动重新构建业务镜像）。
3. `docker compose ps` 确认全部 `healthy`。
4. 失败回退：`docker compose down && git checkout <上版> && ./deploy.sh --env prod`。

见《运维手册》备份章节与 `infra/scripts/` 下 `backup`/`restore` 脚本（各有 `.sh` 与 `.ps1`）。
