# 用户手册

## 登录（进入项目三步：后端服务器＋前端本地）

前置：服务器已一块部署和我恋爱吧＋管理后端（同库 `lovewithme-network` 内直连）；
本地 `VITE_API_BASE_URL` 指向服务器管理后端，`JWT_SECRET` 与服务器同源。

1. 确认服务器管理后端健康：
   `GET http://<服务器>:3100/api/jian-kang` 应 200。
2. 启动本地管理前端（5175）：
   ```powershell
   cd 恋爱吧管理中心
   ./本地启动.ps1 -env dev
   ```
   脚本校验远端后端健康后，只起本地前端（5175）＋语音（8001），本地不拉后端进程、不直连数据库。
   打开 http://localhost:5175/，进入管理员登录页。
3. 账号密码登录：
   1. 输入管理员手机号与密码（管理后端直连同库验密后签发管理令牌）。
   2. 成功后进入账号管理页；后续请求头自动携带该令牌。
   3. 账密错回 400，令牌失效（401）时仅清除本地令牌并在当前页提示，需重新登录，不会自动跳转。
   4. 非管理员命中 403 `WU_GUAN_LI_QUAN_XIAN` 属门禁正常，请换管理员账号。

## 七部卷宗（页面路由）

`/zhang-hao` 账号列表（含封禁级别列）→ `/zhang-hao/:yongHuId` 账号详情（含封禁级别/违规次数/申诉状态/账号解封时间）；
`/liao-tian` 聊天记录（单聊/好友双模式）；`/si-kao-lian` 思考链（回放以落库为准，缺表时诚实降级提示）；
`/feng-jin` 封禁管理（账号封禁分页总数）；`/shen-ji` 审计日志（多维筛选保留导出）；`/tong-ji` 统计图表（总数留存用量）；`/shen-he` 审核运营（举报工单公告活动实验一审二审批量留痕）。

## 数据大屏（/dashboard）

五项指标＋注册/消息/阶段/人设/AI 用量/留存/挑战排行图表＋最近同步日志。
右上角可进 AI 助手、运营看板、编排。

## AI 助手（/assistant）

输入运营问题回车发送，流式回答；工具调用显示摘要行；失败显示红色边框，可重试。
无模型密钥时回答会失败但不崩溃（见 FAQ）。

## 运营看板（/ops）

数仓血缘、七日类型成功率/耗时/迟到标记、质量告警（近 20 条）。

## 可视化编排（/orchestrate）

1. 左侧点选添加 8 类节点；拖拽连线；点击节点右侧填参数 JSON。
2. 顶部填流程名与输入 JSON → 保存 → 运行，节点按回放着色。
3. 审批节点挂起后，用批准/驳回按钮填执行号继续。
4. 导出 YAML 可复制存档（导入走 API）。

## 报表下载（需登录后取 JWT，或用内部令牌）

- Excel：`GET http://localhost:8000/api/v1/reports/日报.xlsx`
- PDF：`GET http://localhost:8000/api/v1/reports/日报.pdf`
