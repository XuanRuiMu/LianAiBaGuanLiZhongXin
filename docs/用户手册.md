# 用户手册

## 登录（进入项目三步：后端服务器＋前端本地）

前置：服务器已一块部署和我恋爱吧＋管理后端（同库 `lovewithme-network` 内直连）；
本地 `VITE_API_BASE_URL` 指向服务器管理后端，`JWT_SECRET` 与服务器同源。

1. 确认服务器管理后端健康：
   `GET http://<服务器>:3100/api/jian-kang` 应 200。
2. 启动本地管理前端（5175）：
   ```powershell
   cd 恋爱吧管理中心
   ./本地启动.ps1 -env dev
   ```
   脚本校验远端后端健康后，只起本地前端（5175）＋语音（8001），本地不拉后端进程、不直连数据库。
   打开 http://localhost:5175/，出现「管理端登录」页。
3. 账号密码登录：
   1. 在「管理端登录」页填「手机号」与「密码」，点「进入管理中心」（管理后端直连同库验密后签发管理令牌）。
   2. 成功后进入账号管理页；后续请求头自动携带该令牌。
   3. 账密错回 400，提示形态为「提示（错误码）」，服务端未回码时不带括号。
   4. 令牌失效（401）时清除本地令牌并送回「管理端登录」页重新登录（续期/注销自身的 401 由调用方处置，不触发跳登录兜底）。
   5. 非管理员命中 403 `WU_GUAN_LI_QUAN_XIAN` 属门禁正常，请换管理员账号。
   6. 三勾选项（登录页）：
      - 「记住账号」：只在本地留手机号用于下次回填，绝不留任何口令。
      - 「记住密码」：勾选后服务端登记持久会话标记并给刷新 Cookie 设 `Max-Age`，关闭浏览器重开仍能免密续上；未勾选则回落为浏览器会话级 Cookie，关窗即失效。**密码/口令本身任何情况下都不落盘，落的是服务端签发的会话凭证。**
      - 「自动登录」：重开浏览器后直接进入、不停在登录页；它依赖「记住密码」，未勾「记住密码」时不可勾选，取消「记住密码」会联动取消「自动登录」。
   7. 自动续期：令牌到点前由前端在访问令牌有效期内单飞续期（同一浏览器并发只会发一次续期请求），保证长时间开着标签页或跨重开仍能免登录。
   8. 「退出登录」：调用 `POST /api/guan-li/tui-chu` 在服务端吊销当前令牌并清发双 Cookie，随后本地会话清空并回登录页；退出后不会被自动登回，回访受保护接口为 401。

## 七个页面（页面路由）

侧栏「管理导航」是七个页面的入口；右上角按钮在当前主题的对照名之间切换（显示「深色」或「浅色」），「退出登录」回登录页。

`/zhang-hao` 账号管理（列表列：昵称、手机号、管理角色、封禁级别、创建时间、操作；「操作」列承载「详情」链接与「授予角色」「回收角色」按钮；
检索组的组说明写明「关键词匹配昵称、用户名或手机号。」，组内填「关键词」「手机号」并配「查询」「重置」，另有仅超级管理员可见的「管理角色」下拉；
页面下方是「接管角色」组：组标题「接管角色」加一条组说明，组内填「角色编号」，按钮为「接管角色」「结束接管」，同样仅超级管理员可见）
→ `/zhang-hao/:yongHuId` 账号详情（用户编号、手机号、性别、人设标签、签名、管理角色、封禁级别、违规次数、申诉状态、账号解封时间、创建时间，「返回」回列表）；
`/liao-tian` 聊天记录（「单聊消息」「好友消息」双页签；「发送方」「排序」是下拉选择，不在输入框里手打原码）；
`/si-kao-lian` 思考链（页签：思考记录 / 记忆 / 对话摘要 / 关键事件 / 接管记录 / 评估；「事件」是下拉选择，回放以落库为准，缺表时诚实降级提示）；
`/feng-jin` 封禁管理（「封禁记录」按 IP 地址查询；「账号封禁与申诉」给出分页总数与「解除封禁」「通过申诉」「驳回申诉」按钮；「提交封禁」卡内「封禁级别」「严重程度」为下拉选择，组说明写明用户编号与 IP 地址填写其中一项）；
`/shen-ji` 审计日志（列：事件类型、用户编号、IP 地址、明细、审计分类、创建时间；「事件类型」「审计分类」为下拉选择，另有用户编号与开始时间/结束时间；「审计保留总数」区块）；
`/tong-ji` 统计图表（「统计天数」为数字输入，默认 30；各图数据点按「字段名：值 单位」给出）；
`/shen-he` 审核运营（页签：举报 / 工单 / 公告 / 活动 / 实验；筛选为「状态」下拉与「只看超时」勾选，按钮为「新建」「初审」「复审」「处理多项」，评审组的组说明为「初审通过进入复审，复审通过即为最终结论。」，页面底部「处理记录」区块列出五类审核对象的处理历史）。

筛选与枚举值一律走下拉或徽标显示名：未收录的原始码显示为「未收录（原始码）」，字段本应有值而服务端未给显示「未记录」，
该字段对这一条记录不适用显示「—」，整表无行显示「暂无数据」，敏感键的键名与值一并显示「已隐藏」。
