# 用户手册

## 登录

打开 http://localhost:5174/，演示账号 `admin / admin123`，成功后进入大屏。

## 数据大屏（/dashboard）

五项指标＋注册/消息/阶段/人设/AI 用量/留存/挑战排行图表＋最近同步日志。
右上角可进 AI 助手、运营看板、编排。

## AI 助手（/assistant）

输入运营问题回车发送，流式回答；工具调用显示摘要行；失败显示红色边框，可重试。
无模型密钥时回答会失败但不崩溃（见 FAQ）。

## 运营看板（/ops）

数仓血缘、七日类型成功率/耗时/迟到标记、质量告警（近 20 条）。

## 可视化编排（/orchestrate）

1. 左侧点选添加 8 类节点；拖拽连线；点击节点右侧填参数 JSON。
2. 顶部填流程名与输入 JSON → 保存 → 运行，节点按回放着色。
3. 审批节点挂起后，用批准/驳回按钮填执行号继续。
4. 导出 YAML 可复制存档（导入走 API）。

## 报表下载（需登录后取 JWT，或用内部令牌）

- Excel：`GET http://localhost:8000/api/v1/reports/日报.xlsx`
- PDF：`GET http://localhost:8000/api/v1/reports/日报.pdf`
