## 真机演练结论（2026-09-07）

本次在开发机 Docker Desktop 上完成真实备份恢复：`mysqldump --add-drop-table` + `pg_dump --clean --if-exists` 落盘，回放均退出码 0。修复两根因：① `backup.ps1` 原未传 MySQL 密码（容器内 `mysqladmin` 报 1045），改用 `docker compose exec -T -e MYSQL_PWD=...` 免警告传密；② `restore.ps1` 原 `Get-Content | docker exec` 传中文 SQL 必坏且 PG 缺 `--clean` 致重放 `already exists`，改为 `docker cp` + 容器内 `mysql < /tmp/恢复.sql` / `psql -f /tmp/恢复.sql`，备份加 `--clean --if-exists` 后幂等可重跑。
