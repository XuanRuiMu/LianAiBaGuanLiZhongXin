# 命名规约与豁免清单（恋爱吧管理中心）

内部标识一律中文；线路层为 ASCII-safe 用 snake_case 拼音；用户可见文本走下面的单源链，链上每一环各有判定口径。

## 用户可见文本单源链（管理前端）

`docs\术语表.md` → `src\术语\<域>.ts` → `src\文案\<域>.ts`（含 `文案\<域>枚举.ts`）＋ `文案\聚合.ts` → `src\枚举映射\<族>.ts` → `src\列定义.ts` → 视图

- `docs\术语表.md` 是唯一显示名真源，`src\术语\<域>.ts` 是它的代码化副本，两侧由 `src\__tests__\术语守卫.test.ts` 双向锁定：改一侧不同步另一侧即判红。
- 词典条目值只能由术语原子组合而来。`文案\<域>.ts` 导出 `<域>文案`，枚举显示名与选项落在 `文案\<域>枚举.ts`，`文案\聚合.ts` 只是给守卫读全量的聚合出口。
- 枚举原码到显示名、以及徽标色调（安/警/危/墨）由 `枚举映射\<族>.ts` 派生；`src\术语.ts` 与 `src\枚举映射.ts` 同为聚合出口，运行侧只有 `src\列定义.ts` 引 `枚举映射.ts` 取 `徽标族` 与取值助手。
- 表头显示名与后端数据键在 `src\列定义.ts` 成对登记，视图不再自写第二份字面量；旧单文件 `src\文案.ts` 已删除，任何指向它的引用都要改到 `文案\` 目录。
- `管理前端\eslint.config.mjs` 的两条内联规则 `local/no-visible-cn-literal`（裸中文上屏，词典坐标只在键位放行）与 `local/no-data-key-literal`（视图自写数据键/中文表名字面量），以及守卫侧的引用形态、死键、术语三向同步、枚举下拉判定口径，逐条写在 `docs\架构文档.md`「工程护栏与度量口径」第一、第九节，本文件不重复粘贴。
- 管理后端可见文字另有单源：`管理后端\src\文案.ts`（含 `字段显示名`）与 `管理后端\src\错误码.ts`，口径见 `docs\架构文档.md` 第七节。
