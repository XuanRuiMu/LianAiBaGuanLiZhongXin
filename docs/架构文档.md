# 恋爱吧数据中心 · 架构文档

定位：可交付、可运维、可测试的 AI 数据平台（AI 问答＋数据大屏＋可视化编排）。

## 服务拓扑（本地默认端口）

| --- | --- | --- | --- |
| analytics-frontend | 5174 | React 18 / Vite 5 / ECharts 5 | 登录/大屏/助手/运营看板/编排画布 |
| backend-java | 8080 | Spring Boot 3.5 / MyBatis-Plus / Kafka | 认证/统计/同步/死信/质量/运营 |
| ai-service | 8000 | FastAPI / LangGraph / MCP | 问答流式/报表/开放平台/编排引擎/检索 |

## 核心链路

1. 问答：前端 SSE → ai 鉴权 → LangGraph 五节点（检查点/HITL）→ 工具总线 → 后端内部接口 → MySQL。
2. 同步：调度器/手动触发 → Kafka → 消费者（执行→dwd→质量→sync_log，失败→死信）→ 死信查询/重放。
3. 编排：画布/DSL → 引擎（ToolRegistry 复用）→ 跨度双写 SQLite＋PG。
4. 报表：定时落盘＋下载端点（openpyxl/reportlab）。
5. 开放：X-API-Key（哈希＋配额）→ 公开统计/工具清单/问答/编排/TTS；Webhook 出站 HMAC 重试，入站签名＋幂等。

## 横切约定

- 成功信封 `{code:200,message,data}`，前端按 200 解包（`http.ts 解析响应信封`）。
- JWT（前端/后端/AI/TTS 同密钥）＋内部令牌（服务间）＋开放密钥（第三方），三轨并存。
- 用户可见文本走文案模块；配置走环境变量/yml；中文标识符。
