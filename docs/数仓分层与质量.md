## 分层（现行：同库直查，无同步链）

| 层 | 表 | 来源 | 说明 |
| --- | --- | --- | --- |
| ODS | 源业务库（PG `love_source`） | 和我恋爱吧生产库导入＋种子 | 只读账号 `readonly` 访问 |
| ODS | `ods_同步批次` | 同步控制器 trigger/replay | 批次接收登记 |
| ODS | Kafka `love.sync.events` | 定时调度器/手动触发 | 同步命令事件 |
| DWD | `dwd_同步明细` | Kafka 消费者执行前后 | 每批次×每类型一行，含耗时 |
| DWD | `sync_log`（既有） | Kafka 消费者 | 执行日志 |
| DWS | `stat_*`（既有 8 表，命名保留兼容 Mapper） | 同步执行器 | 汇总统计 |
| DWS | `dws_质量记录` | 质量校验服务 | 每批次×每检查项一行 |
| DWS | `dws_调度日报` | 运营服务总览时聚合落盘 | 按天×类型成功率 |

血缘：ODS.源业务库 → ODS.Kafka同步事件 → DWD.同步明细 → DWS.汇总统计 → DWS.质量记录 → DWS.调度日报（运营看板 `/ops` 实时展示）。

## 质量校验（`质量校验服务`，阈值 `app.quality.volatility-threshold` 默认 0.5）

| 检查项 | 口径 | 超限动作 |
| --- | --- | --- |
| 行数非负 | 本次同步行数 ≥ 0 | 落表＋告警日志 |
| 波动阈值 | \|本次−上次\|/上次 ≤ 0.5 | 落表＋告警日志 |
| 主键唯一 | 目标表总数 ＝ 去重数 | 落表＋告警日志 |
| 目标表非空 | 目标表行数 ＞ 0 | 落表＋告警日志 |

质量链失败只记日志，绝不阻断同步主流程。告警查询：`GET /api/v1/ops/overview` 的 `质量告警` 段。

## 报表

- 下载（均需凭证）：`GET /api/v1/reports/日报.xlsx`、`GET /api/v1/reports/日报.pdf`。
