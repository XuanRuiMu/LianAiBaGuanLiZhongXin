# 故障排查手册（现象 → 原因 → 命令 → 解决）

## 后端 /health 返回 401

- 原因：Jwt 过滤器放行名单与安全配置不一致（已修，见 Jwt 免凭证测试）。
- 命令：`curl -s http://localhost:8080/health`
- 解决：确认 `Jwt认证过滤器.shouldNotFilter` 含 `/health` 与 `/api/health`。

## 登录成功不跳转

- 原因：前端把信封 `code:200` 误判为失败（已修，`解析响应信封`）。
- 命令：浏览器 F12 看 `/api/v1/auth/login` 响应。
- 解决：升级到含 `http.ts 解析响应信封` 的版本。

## 同步 FAILED：Failed to obtain JDBC Connection

- 原因：源库只读账号缺失或密码不对。
- 命令：`GET /api/v1/sync/dlt` 看批次错误。
- 解决：对齐 `SOURCE_PG_USERNAME/SOURCE_PG_PASSWORD` 与
  `infra/source-postgres/init`；旧数据卷需重建 readonly 密码
  （`ALTER ROLE readonly PASSWORD '...'`）。

## 报表下载 401

- 原因：AI 与后端 JWT 密钥不一致（多终端手工启动易犯）。
- 命令：对比两边进程环境 `JWT_SECRET`。
- 解决：统一用 `本地启动.ps1 -env dev` 启动。

## n8n 自定义节点不识别

- 原因：`n8n execute` CLI 不加载自定义扩展（n8n 行为，非本项目 bug）。
- 命令：`docker logs love-n8n | grep liaolian` 确认加载。
- 解决：走服务端运行（Webhook/API）或节点直驱验证。

## 模型下载不动

- 原因：镜像站大文件停滞、官方源限速。
- 命令：看 `~/.cache/huggingface/hub` 内 `.incomplete` 大小是否增长。
- 解决：换网络后用 `huggingface_hub.snapshot_download` 续传；
  未完成前检索走全文降级，评测自动跳过。

## Docker 守护进程掉了

- 现象：`docker ... failed to connect ... dockerDesktopLinuxEngine`。
- 解决：重开 Docker Desktop，容器（unless-stopped）会自动恢复；
  宿主进程服务用 `本地启动.ps1` 重拉。
