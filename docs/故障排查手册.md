# 故障排查手册（现象 → 原因 → 命令 → 解决）

## 语音 /health 不通

- 原因：容器未就绪或宿主 8001 被占。
- 命令：`curl -s http://localhost:8001/health`
- 解决：`cd infra && docker compose ps` 看 `tts-service` 状态；改 `TTS_PORT` 后重起。

## 语音合成 401

- 原因：管理令牌无效/过期，或两边 `JWT_SECRET` 不同源。
- 命令：确认 `VITE_API_BASE_URL` 指向的服务器与本地 `JWT_SECRET` 同源。
- 解决：用管理员账密重新登录拿新令牌；服务器轮换密钥后本地同步更新。

## 管理后端 /api/jian-kang 不通

- 原因：服务器后端未部署，或本地 `VITE_API_BASE_URL` 指错。
- 命令：浏览器直访 `http://<服务器>:3100/api/jian-kang`。
- 解决：服务器 `cd infra && ./deploy.ps1 -env prod` 重部署；本地检查 `VITE_API_BASE_URL`。

## 管理登录 400 账密错

- 原因：手机号非管理员行，或密码不对。
- 命令：服务器库查 `SELECT "用户名","管理员" FROM "用户" WHERE "手机号"=$1`。
- 解决：确认管理员行后用正确密码登录；403 则为旗标非管理员，换账号。

## 共享库连不上

- 原因：和我恋爱吧侧 postgres/redis 未启动，或同源键未补齐。
- 命令：`docker network inspect lovewithme_lovewithme-network` 确认管理容器在网内。
- 解决：先起和我恋爱吧侧中间件；确认 `和我恋爱吧/.env` 存在且可读。

## 外部网络不存在

- 现象：`docker compose up` 报 `network lovewithme-network declared as external, but could not be found`。
- 解决：先在和我恋爱吧侧 `docker compose up -d postgres redis` 建网后再起管理中心。

## n8n 自定义节点不识别

- 原因有二：① 工作流 JSON 里节点类型缺 `CUSTOM.` 前缀（n8n 2.x 把自定义节点注册为
  `CUSTOM.liaolian*`，裸名 `liaolian*` 运行时报 `Unrecognized node type`，已修：
  `workflows/*.json` 均已加前缀）；② `n8n execute` CLI 与服务端抢 5679 任务端口，
  需先 `docker compose stop n8n` 再用 `docker compose run --rm --no-deps n8n execute --id=<id>`
  （`package.json` 的 `n8n.nodes` 路径已对齐 `dist/nodes/*.node.js`）。
- 命令：`docker exec love-management-n8n n8n export:nodes | grep CUSTOM` 确认 4 个 `CUSTOM.liaolian*`；
  `docker exec love-management-n8n n8n import:workflow --input=/tmp/xxx.json`（JSON 须带 `id` 字段）导入。
- 验证（2026-09-07）：`每日运营统计`（查询统计返回 totalUsers 120）与 `编排触发`
  （取数 42）均在服务端内 `Execution was successful`。

## Docker 守护进程掉了

- 现象：`docker ... failed to connect ... dockerDesktopLinuxEngine`。
- 解决：重开 Docker Desktop，容器（unless-stopped）会自动恢复；
  本地前端用 `本地启动.ps1` 重拉。
