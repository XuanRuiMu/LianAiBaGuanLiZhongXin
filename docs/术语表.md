# 恋爱吧管理中心 · 术语表

权威性：本表是管理端可见文字的唯一来源。`管理前端\src\术语\<域>.ts`（按域具名原子）与其聚合出口 `管理前端\src\术语.ts` 是本表的代码化副本，两者由 `管理前端\src\__tests__\术语守卫.test.ts` 强制双向一致；任何一侧改动必须同步另一侧，否则测试判红。

口径边界：本表只管中文显示名与书写方式，不改接口字段名（拼音键名一律不动）。值域列出的原始码来自 `docs\契约.md` 与 `管理后端\src\校验.ts`，出处在表内标注。

## 一、为什么需要本表

改造前有四类病灶：词典自带字面量导致同一概念多份写法、无机制护栏阻止旧称回流、表头与数据键两处独立定义、枚举原码直上屏。本表治前两类，是 `术语\<域>.ts → 文案\<域>.ts → 枚举映射.ts → 列定义.ts → 视图` 单源链的第一环（术语与文案都按业务域拆文件，`术语.ts` 与 `文案/聚合.ts` 只是给守卫读全量的聚合出口，运行侧不得引）。

## 八、书写规约

1. 一个概念一个名字。旧称写进 `禁用别名`，守卫扫描词典条目值、词典键名与视图模板文本节点，命中即红。键名扫描覆盖全部分类（`文案\<域>.ts`），其余分类里沿用的旧称键名随 FP-08 的 eslint 规则一并收口。
2. 表头与字段标签只写名词，不带括号补充。必填语义由校验错误消息表达，可选一律不标注。占位提示只在能提供标签之外的额外信息时出现，禁止与同一字段的标签同句重复。
3. 按钮与操作标签 = 动词 + 宾语，一眼看懂"对什么做这件事"。内部黑话（夺舍、归还、一审、二审、批量、高危、留痕）不得出现在可见文字里，定名前必须读后端实现确认语义。
4. 不向管理员叙述实现。Redis、REDIS_URL、Socket、落库、读写分离、掩码、留痕、服务端原样返回、直连同库、事务、SQL 等词禁止上屏；只给结论和下一步动作。
5. 反馈一操作一文案，禁止跨操作复用同一条。
6. 排版：中文与英文或数字之间加一个半角空格，写作 `IP 地址`、`封禁 1 分钟`。全库由守卫校验。
17. 空态三形态互斥，一格只出一种：「—」= 该字段对这条记录**不适用**（值域依赖列，如 `账号解封时间` 在 `封禁级别`＝正常时）；「未记录」= 该字段本应有值而服务端没给；「暂无数据」= 整表/整块无行。同一行既渲染出「缺席即确定态」的确定态（正常/无申诉/无管理身份）又渲染出「未记录」，而该列其实依赖那个确定态，即语义自相矛盾，判红。登记面只有 `管理前端\src\列定义.ts` 的 `值域依赖` 一处，`列守卫` 逐列反查。枚举筛选入口一律 `<select>`：凡标签等于 `列定义.ts` 里徽标/枚举列表头显示名的输入项，都必须在 `枚举映射/<族>.ts` 导出选项数组并下拉选择，禁止让管理员手打拼音码；提交的参数名与取值码一字不动，由 `视图守卫` 断言 option 文案全部来自映射。
18. 词典值不得含悬空的拉丁占位符（`N`、`X`、`NN` 这类未定义字母位）；要表达数值就用具名量词写死（`统计天数`），不写「近 N 天」。合法拉丁只允许出现在已登记术语的显示名里（`IP 地址`、`UUID`）与错误码形态（`[A-Z_]{4,}`）中，由 `术语守卫` 全域扫描。结构体内部键同理：已登记术语/数据键出中文显示名，未登记的保持原形但整段以「名：值；名：值」可读形态呈现，禁止把 `{"a_b":1}` 这类裸 JSON 打上屏；含敏感语义的键（密码/密钥/token/secret 类）键名与原值一并走「已隐藏」。
7. 超出长度预算即视为歧义或冗余信号，必须拆分或删除，不允许靠缩写蒙混。
8. 词典条目值必须由 `术语\<域>.ts` 的具名原子组合而来；已在术语表登记的概念，词典里不允许出现第二份手写字面量。
9. 枚举值区分三态：命中值域显示中文名、字段语义为无值显示未记录、未命中显示未收录（原始码）。禁止把未命中值当作确定态。
10. 缺席即确定态：服务端用 LEFT JOIN 缺席或旗标推导表达一个确定状态时，空值必须显示该确定态而不是「未记录」——封禁级别 NULL→正常（绿色徽标）、申诉状态 NULL→无申诉、管理角色 NULL→无管理身份（`管理后端\src\路由\账号.ts:67` 的 LEFT JOIN 与 `脱敏列表行`/`补角色` 推导）。真正语义为"字段无值"的（解封时间、原文长度、空单元格）才用「未记录」。这三族的空态显示名由 `管理前端\src\枚举映射.ts` 按族显式传入，禁止共用一个全局兜底。
11. 表头与后端数据键必须在 `管理前端\src\列定义.ts` 成对声明，视图不得再各写一份字面量；列契约由 `管理后端\tests\单元\列契约.test.ts` 双向比对后端 SQL 实际列。
12. 徽标色调（安/警/危/墨）由 `枚举映射.ts` 的族色调表随显示名一同派生，视图禁止用 `v-if` + 裸码比较自定色调。
13. 同一页面确需两个显示名相同的输入标签时（如封禁写入与封禁查询都要填 IP 地址），两者必须分处两个带标题的输入组之下，组标题取自词典且互不相同、不得为空；组内某字段服务于多种对象或多种轮次时，该组还须渲染一条取自词典的组说明（如评审组的「初审通过进入复审，复审通过即为最终结论。」），说明只在词典里挂着而无渲染点即判红。禁止靠括号补充、禁止另起第二个显示名。
14. 视图渲染服务端行数据只允许 `列定义.ts` 白名单内的数据键上屏，未登记键名一律不渲染；服务端派生字段（如详情接口的正文）不得回填进行数据行。
15. 后端读接口一律写显式中文列清单（`AS "中文列"` 别名），禁止 `SELECT *` 透传。一张表的列定义 = 后端返回列 ∪ 未上屏登记，两侧由 `管理后端\tests\单元\列契约.test.ts` 双向比对，且列清单还要与真实库 `information_schema.columns` 一致；快照按登记列**全量**逐列输出「中文列名：值」。收窄白名单来绕过缺出处的列即信息量塌陷，禁止；列无出处时先把后端列清单显式化。
16. 数值上屏必须同时给出字段名与单位，形如 `数量：3 条`；图表数据点的 tooltip 也不例外，只写「日期：值」这类无字段名无单位的裸拼接判红。字段名取 `列定义.ts` 登记的表头，单位取术语 `条目单位`（词典里由 `通用.总数后缀` 与 `统计.数量单位` 引用同一份），「字段名：值」的拼接只允许由 `列定义.ts` 的 `命名值文本` 完成，视图不得自写分隔符。

## 十、护栏生效方式

- `docs\术语表.md` 与 `管理前端\src\术语.ts` 双向一致，由守卫测试逐行比对：文档改了代码没改判红，代码改了文档没改判红。
- 禁用别名与书写规约的禁用词，扫描 `文案\*.ts` 全部条目值、已收口分类的键名与视图模板文本节点；命中即红。当前例外只在守卫测试的豁免清单里逐条登记，视图落地完成后收紧。
- 快照列契约扫描：`管理后端\tests\单元\列契约.test.ts` 实解析 `管理后端\src\路由\思考.ts` 的显式列清单，与 `管理前端\src\列定义.ts` 的登记列、真实库 `information_schema.columns` 三方比对；`管理前端\src\__tests__\列守卫.test.ts` 从前端侧复核同一份清单。数据库未配置连接串时该项跳过，配置了却不可达即判红。
- 词典死键扫描：每个键至少被以 `域文案.键` 成员访问或被引号键名引用一次；本阶段仅视图尚未接入的新键可临时登记豁免。
- 守卫自带反证用例：喂入已知违规样张时必须判红，防止护栏空跑。
